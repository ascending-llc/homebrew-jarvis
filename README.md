# ASCENDING Jarvis Tap

Homebrew tap for [Jarvis Registry](https://github.com/ascending-llc/jarvis-registry) tooling.

## Install

```
brew tap ascending-llc/jarvis
brew install ascending-llc/jarvis/jarvis-registry
```

Upgrade with `brew upgrade jarvis-registry`.

## Formulas

Formulas in `Formula/` are generated and pushed automatically by [GoReleaser](https://goreleaser.com/) from [`ascending-llc/jarvis-registry-cli`](https://github.com/ascending-llc/jarvis-registry-cli) on every tagged release. Don't edit them by hand — changes will be overwritten on the next release.
